Secrets and settings for agents and Git. Credentials stay on your machine and reach a guest only when it needs them.

### Get started
Install the three binaries with Homebrew, sign Claude in with rix, and run `rux`. The [installation guide](__BASE__/getting-started/installation/) covers release archives and what each backend needs; the [quick start](__BASE__/getting-started/quick-start/) goes end to end.
</div>

```sh
brew install rex-agents/tap/r-x
rux
```
